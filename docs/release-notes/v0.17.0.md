## AI-intoU v0.17.0 — 多用户

### 新功能
- **邀请码注册**：设置 → 账号登录 → 「有邀请码？注册新账号」
- **AI 接入**：为 RikkaHub、Cherry Studio、Claude Desktop 等 AI 客户端生成专用 token，可以单独撤销；能一键复制 MCP URL、请求头或完整 JSON
- **管理页**（开发者模式，仅 owner 可见）：生成和撤销邀请码；停用、启用账号，重置密码
- **首次使用引导**：设置页顶部的「三步开始使用」

### ⚠️ 不兼容变更
- 静态 Bearer Token 停用：请改用账号登录，或者手机 token（`aiu_phone_…`）
- AI 客户端要换成在「AI 接入」里新生成的 token（`aiu_agent_…`）
- 服务端要同时升级，升级步骤见 `docs/MULTI-USER.md`

### 安装
下载下面的 `AI-intoU-v0.17.0.apk`。如果手机上装的是 debug 版，要先卸载再安装。
