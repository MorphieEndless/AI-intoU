## AI-intoU v0.19.0 — 应用内更新 + 细节打磨

### 新功能
- **应用内「检查更新」**：设置页直接查 GitHub Releases，能看到最新版本号、发布时间和完整更新说明，不用再手动开浏览器找包
- **多镜像源下载**：点「下载更新」时对 GitHub 官方和多个公共镜像并发测速，自动挑最快的源交给系统下载管理器下载；应用内实时显示进度、速度和当前来源，中途可取消，失败或卡住自动换源
- **下载后三重校验**：文件大小 + GitHub 提供的 SHA-256 + 包名 / 版本 / 签名证书与已安装 App 一致，任何一项不符都自动删除安装包，防止二改包冒充

### 修复与优化
- **波形库大提速**：只在启动时加载一次，磁盘缓存冷启动秒开，切 Tab 不再重复发请求；样条曲线进程级缓存 + 播放游标独立绘制，播放不再整图重绘；服务端支持 ETag/304 条件请求
- **「管理」入口回归**：修复关闭开发者模式后「管理」跟着消失的问题，现在它只看 owner 身份，开发者模式只控制「协议调试」
- **吮吸档位自然表述**：玩具预设改为「颤动 / 深吸 / 先短后长」，自由组合的「节奏 B」改为「规律吮吸」，和其他档位文案对齐（仅显示文案，协议不变）
- **细节统一**：「管理」「AI 接入」右上角刷新统一为文字按钮；移除「另有 x 个已撤销或过期的 token 未显示」提示行

### ⚠️ 升级注意
- **零新增权限**：更新包交给系统下载管理器下载，安装由系统应用发起——下载完成后点通知栏里系统的「下载完成」通知即可安装，AI-intoU 不申请「安装未知应用」，也不需要存储权限。Android 13 及以下的部分系统点通知后不会弹出安装界面，这时请用「在浏览器中打开 Release 页面」下载安装
- **服务端**：`GET /patterns` 新增 ETag 支持，建议同步升级到本 tag 以享受 304 省流；旧版服务端也能用，只是没有这项优化
