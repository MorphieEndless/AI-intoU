## AI-intoU v0.19.0 — App 内检查更新 + 体验修正

### 新功能

- **App 内检查更新**（设置 → 检查更新）：
  - 直接读取 GitHub 最新 Release，展示版本号、发布日期、包大小和完整更新说明
  - 下载时从 GitHub 官方源和多个公共镜像并发测速，自动挑最快且返回有效 APK 的源；失败自动换源，实时显示进度、速度和来源，可取消
  - 三重校验：下载后核对包大小与 SHA-256，安装前核对包名、versionCode 递增、签名证书与已安装应用一致，任一不符拒绝安装
  - **新增权限**：`REQUEST_INSTALL_PACKAGES`（安装未知应用）。仅在点「安装」时由系统单独授权，可随时在系统设置里关闭；不用此功能也可以在浏览器里打开 Release 页面手动下载
- **波形库大幅提速**：只在应用启动时加载一次，切页零网络请求；磁盘缓存冷启动秒开 + 后台静默校验；ETag/304 条件请求；波形曲线进程级缓存 + 播放游标分离绘制

### 修复与调整

- **修复**：关闭「开发者模式」后「管理」页也跟着消失的问题。现在「管理」只对 owner 可见，开发者模式只控制「协议调试」
- **吮吸档位文案**与波形库风格统一：玩具预设「颤动 / 深吸 / 先短后长」，自由组合「规律吮吸」。仅改文案，协议行为不变
- **AI 接入**：移除「另有 x 个已撤销或过期的 token 未显示」提示行
- **刷新按钮统一**：「管理」「AI 接入」右上角的刷新图标改为与波形库一致的文字按钮

### 安装

下载下面的 `AI-intoU-v0.19.0.apk` 覆盖安装（签名一致可直接升级）。如果手机上装的是 debug 版，要先卸载再安装。

服务端无需升级。
