# 更新说明（Release Notes）

每个版本一个文件：`vX.Y.Z.md`（与 git tag 同名）。文件正文就是 GitHub Release 的
正文，`release.yml` 发布时原样取用。

**已发布的文件不回改。** 写错了就发新版本说明更正；历史文件保持发布时的样子。

写作规范（两部分结构、「服务端」必填句）见仓库根目录 `AGENTS.md` §5。

## 模板（复制后替换尖括号内容）

```markdown
## AI-intoU vX.Y.Z — <一句话主题>

### 客户端

#### 新功能
- <条目>

#### 修复与优化
- <条目>

#### ⚠️ 升级注意
- <条目，没有可省略>

### 服务端

此版本服务端需要更新至 vX.Y.Z 版本以适配。

- <变更点>
- 升级步骤：<步骤>

> 本版服务端没有改动时，整个「服务端」一节省略。

### 安装
下载下面的 `AI-intoU-vX.Y.Z.apk`。如果手机上装的是 debug 版，要先卸载再安装。
```
