# 01 — 产品定义与已锁定决策

> 本文档回答「我们到底在做一个什么东西」。所有决策均由项目所有者
> 在 2026-09-21 的评审中锁定。变更需走 ADR 流程。

## 1. 产品定位

AI-intoU（樱趣）是一个**自部署**的 AI 远程玩具控制桥：
上游接任意 MCP 兼容的 AI 客户端，下游经手机 App 蓝牙直连玩具。

- **部署形态**：单实例、单进程、SQLite。不为多实例水平扩展设计。
- **使用规模**：所有者自用 + 小范围分享（注册可开关，量级 ≤ 数十人）。
- **许可规划**：分段 AGPL —— 小范围非商业使用自由，大规模/商业使用需联系作者。
  （与代码仓库 License 声明同步推进，当前仓库 License 待定。）
- **开源状态**：当前私有，未来公开。设计文档与代码均按「会被公开阅读」的标准写。

## 2. 角色模型

| 角色 | 说明 | 认证方式 |
| --- | --- | --- |
| **Owner（部署者）** | 第一个账号，拥有管理权限（建用户、管所有 token） | 账号密码登录 → 会话凭证 |
| **User（用户）** | 普通账号，管理自己的 token / 设备 / 安全配置 | 账号密码登录 → 会话凭证 |
| **AI Agent（AI 代理）** | 某个平台上的 AI 客户端（Claude Desktop、RikkaHub……）。**一个平台 = 一个独立 token** | `agent` 类 API Token |
| **Phone Relay（手机中继）** | 装在玩具旁边的 Android App，维持 WSS 长连接 | `phone` 类 API Token |
| **（伏笔）Human Operator** | 未来可能引入的人类远程操控者 | `human` 类 API Token（**本期不实现**，仅在数据模型与文档中预留） |

关键关系：

```
User 1 ──── n API Token（agent / phone / human*，可命名、可撤销、可过期）
User 1 ──── n Device（数据模型预留；v1 仅允许 1 台手机在线）
User 1 ──── n Pattern（自定义波形）
User 1 ──── 1 SafetyConfig（跟随全局默认 + 个人覆盖）
```

## 3. 已锁定决策

### D1 — 统一身份与令牌体系
三套半认证体系合并为一个：
- **人类**用账号密码换取短期会话凭证（Web 管理页 / CLI 用）。
- **机器**（AI 代理、手机）用**长期 API Token**：不透明随机串、数据库只存哈希、
  可命名、可单独撤销、可设有效期、按 `kind` 分类互不通婚。
- 静态 Bearer Token 模式**移除**，由首次运行向导创建 owner 账号 + 首批 token 替代
  （保留单用户场景的易用性，提供迁移路径）。

### D2 — 每平台一个 AI Token
每个 AI 平台一个独立可命名 token（如 `claude-desktop`、`rikkahub-phone`），
可单独撤销。撤销某个 AI 的访问权不影响其他平台，也不需要改密码。

### D3 — 设备模型：一对一实现，一对多预留
- v1：一个用户同时只允许一台手机在线（新连接顶替旧连接，与现状一致）。
- 数据模型中 Device 是独立表、token 可绑定设备槽位，为多手机/多玩具留好扩展空间。
- 手机与 AI 使用不同 kind 的 token，权限互不相通。

### D4 — OAuth：本期移除，等真实用户需求再回归（修订于 2026-09-21）
（背景：OAuth 流程是给 claude.ai 远程 MCP 连接器用的——claude.ai 要求
自定义连接器必须走标准 OAuth 授权码流程，不能直接粘贴 token。
该模块并非所有者亲手决策的产物，目前无人使用。）
- 重构中**删除** OAuth 模块（`oauth.py` / `oauth_routes.py` / 独立 OAuth 库），
  不做 claude.ai 连接器兼容。
- claude.ai 用户可改用支持自定义请求头的 MCP 客户端（如 RikkaHub），
  以 agent token 接入。
- 若有真实用户提出 claude.ai 直连需求，再以「OAuth 插件」形式设计回归，
  且签发的凭证必须落地为普通 agent token，不得平行维护凭证体系。

### D5 — 注册默认关闭
面向小圈子部署，`SB_REGISTRATION_OPEN` 默认值从 `true` 改为 **`false`**。
Owner 通过 CLI / 管理页创建账号；确需开放时再打开。
（这是对现状行为的**有意变更**，迁移指南中说明。）

### D6 — 人类远控伏笔
数据模型的 token `kind` 枚举包含 `'human'`，文档提及，本期不实现任何相关逻辑。

## 4. 本期非目标（Non-Goals）

明确**不做**的事情，防止范围蔓延：

- ❌ OAuth / claude.ai 连接器兼容（直到有真实用户提出需求）
- ❌ 多实例部署 / 水平扩展 / 外部 Redis
- ❌ RBAC 角色权限系统（只有 owner 与普通用户两档）
- ❌ 审计日志、操作流水
- ❌ 人类远控（仅预留数据模型）
- ❌ Web 管理页（列入后期里程碑 M7，本期只做 API + CLI）
- ❌ 账号体系的邮箱验证、找回密码（小圈子场景，owner 手动重置即可）
